# objects — nouns

One job: hold one card per load-bearing noun. Cluster by how an editor asks, not by HTML order.

## Inputs

- Working (this run): a name from `_index.md`
- Reference (every run): `../../_templates/object.md`
- Reference (every run): `../../_meta/schema.md`

Do NOT load: all cards in this folder.

## Process

1. Read `_index.md`.
2. Open one card.
3. New noun = copy the template; add a catalog line first.

## Outputs

- The card you opened or created. `_index.md` stays one line per noun.

## Human check

`status: verified` has a date, commit, and citation. Otherwise it is `stub`.
